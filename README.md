# SmartAppWear ⌚

Proyecto académico desarrollado para Wear OS (API 37) utilizando Jetpack Compose Material 3 en Android Studio.

## Integrantes del Equipo
* Brandon Alexis Sanjuan Enriquez
* Yahir Emanuel Martinez Gonzalez
* Jose Alfredo Cortes Villarreal

## Descripción del Proyecto
Aplicación para dispositivos wearables enfocada en un caso de estudio de salud y bienestar. Incluye:
- **Medición de Ritmo Cardíaco** (Simulación de datos en tiempo real).
- **Conteo de Pasos** (Monitoreo de metas diarias).
- **Panel de Configuración** (Gestión de modos y versión).

## Características Técnicas
- Interfaz circular optimizada para pantallas Wear OS.
- Navegación fluida por estados con Jetpack Compose.
- Sincronización y vinculación mediante emulador Wear OS Large Round y Pixel 7.
